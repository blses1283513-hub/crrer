# Firefly III 財務結構設計

> 一行原則：**帳戶記「錢在哪」，分類記「錢為什麼動」，預算記「我允許它動多少」。**
> 三者分開，報表才乾淨。

## 0. 核心觀念（先讀這段，少走冤枉路）

Firefly III 是**複式記帳**：每一筆交易都是「從 A 帳戶 → 到 B 帳戶」。

| 交易類型 | 從 | 到 | 例子 |
|---|---|---|---|
| 支出 Withdrawal | 資產帳戶 | 支出帳戶 | 玉山存款 → 全聯 |
| 收入 Deposit | 收入帳戶 | 資產帳戶 | 公司 → 玉山存款 |
| 轉帳 Transfer | 資產帳戶 | 資產帳戶 | 玉山存款 → 玉山信用卡（繳卡費） |

**最容易犯的錯：把「繳信用卡費」記成支出。** 刷卡當下已經記過支出了，繳卡費只是把錢從存款搬到信用卡帳戶，必須是**轉帳**，否則支出會被算兩次。`規則.md` 的第 1 組規則專門處理這件事。

主要幣別：**TWD（新臺幣）**。第一次註冊時選定，之後在「選項 → 貨幣」可啟用 USD / JPY 等外幣。

## 1. 資產帳戶（錢在哪）

| 帳戶名稱 | 角色 (Account role) | 說明 |
|---|---|---|
| 玉山存款 | 預設資產帳戶 Default asset | 薪轉、日常扣款的主帳戶 |
| 玉山信用卡 | 信用卡 Credit card | 餘額為負＝欠款；設定每月繳款日 |
| 現金錢包 | 現金錢包 Cash wallet | 身上的現金 |
| 悠遊卡 | 現金錢包 Cash wallet | 加值＝從存款轉帳過來；搭車＝支出 |
| 緊急預備金 | 儲蓄帳戶 Savings | 存錢筒掛在這裡（見第 5 節） |

> 有其他銀行帳戶就照樣新增一個資產帳戶，名稱用「銀行＋用途」，例如「台新 Richart 活存」。
> 開帳時填入**開戶餘額 (opening balance)** ＝ 開始記帳那天的實際餘額，不必補記過去的交易。

## 2. 收入帳戶 / 支出帳戶（錢從哪來、去哪裡）

- **收入帳戶**：`公司名稱`（薪資）、`副業客戶`、`玉山銀行利息`、`統一發票中獎`。
- **支出帳戶**：**不用事先建立**。匯入時 Firefly III 會依 CSV 的商家名稱自動建立（例如「全聯福利中心」）。之後若同一家店出現多種寫法，再到「帳戶 → 支出帳戶」合併。

## 3. 分類 Categories（錢為什麼動）

收支共用同一套分類清單。刻意壓在 **5 個收入 + 13 個支出**：分類太細，月底就沒人想看。

### 收入分類
| 分類 | 包含 |
|---|---|
| 薪資 | 月薪 |
| 獎金 | 年終、績效、三節獎金 |
| 副業收入 | 接案、稿費、講課 |
| 利息與股利 | 存款利息、股票股利 |
| 其他收入 | 發票中獎、退稅、二手拍賣 |

### 支出分類
| 分類 | 包含 | 對應預算 |
|---|---|---|
| 餐飲 | 三餐、外送、飲料、超商食物 | 生活費 |
| 日用品 | 全聯、家樂福、藥妝 | 生活費 |
| 交通 | 捷運、高鐵、台鐵、加油、停車、Uber | 生活費 |
| 居住 | 房租、管理費、水電瓦斯 | 固定支出 |
| 通訊網路 | 手機月租、家用網路 | 固定支出 |
| 訂閱服務 | Netflix、Spotify、YouTube Premium、iCloud | 固定支出 |
| 保險 | 壽險、醫療險、意外險 | 固定支出 |
| 醫療保健 | 看診、藥品、健身 | 生活費 |
| 娛樂休閒 | 電影、遊戲、展覽、興趣 | 想要 |
| 服飾美容 | 衣服、鞋、理髮 | 想要 |
| 學習成長 | 書、課程、證照 | 想要 |
| 人情社交 | 聚餐請客、紅白包、禮物 | 想要 |
| 旅遊 | 機票、住宿、旅途花費 | 想要 |

> 若某筆真的無法歸類，先放著不分類；月底檢查「無分類」報表時再決定（見 `README.md` 的每月流程）。**不要建「其他支出」分類**，它會變成黑洞。

## 4. 預算 Budgets（允許它動多少）

採「需要 / 想要 / 儲蓄」三層。只有 **3 個預算**，每月自動重設（auto-budget：每月固定金額）。

| 預算 | 涵蓋分類 | 建議比例 | 月收入 NT$50,000 範例 |
|---|---|---|---|
| 固定支出 | 居住、通訊網路、訂閱服務、保險 | 35% | NT$17,500 |
| 生活費 | 餐飲、日用品、交通、醫療保健 | 30% | NT$15,000 |
| 想要 | 娛樂休閒、服飾美容、學習成長、人情社交、旅遊 | 15% | NT$7,500 |
| （儲蓄，不設預算） | 轉入存錢筒 | 20% | NT$10,000 |

- 設定方式：預算 → 建立 → 「自動預算」選 **每月固定金額 (Set a fixed amount every period)**。
- 預算由 `規則.md` 依分類自動指派，平時不用手動選。
- 先照比例跑 2 個月，再依實際數字調整；**目標是誠實，不是好看**。

## 5. 存錢筒 Piggy banks（儲蓄目標）

全部掛在「緊急預備金」儲蓄帳戶下（也可以分開掛到不同帳戶）。

| 存錢筒 | 目標金額 | 期限 | 說明 |
|---|---|---|---|
| 緊急預備金 | 6 × 每月必要支出（例：NT$195,000） | 無 | **第一優先**，填滿前其他目標放慢 |
| 年度保險費 | 年繳保費總額 | 每年繳費月 | 年繳費用每月平均存，避免繳費月爆掉 |
| 旅遊基金 | 自訂（例：NT$40,000） | 預計出發月 | |
| 3C／大型採購 | 自訂（例：NT$30,000） | 無 | 手機、電腦汰換 |

> 運作方式：每月發薪後，從「玉山存款」轉帳到「緊急預備金」，再把金額分配到各存錢筒。存錢筒是**帳戶內的分帳標記**，不是另一個帳戶。

## 6. 帳單 / 訂閱 Bills（新版介面稱「訂閱 Subscriptions」）

設定預期金額範圍與週期，Firefly III 會提醒「這個月該付的還沒付」。用 `規則.md` 第 3 組規則自動連結交易。

| 帳單 | 金額範圍 (NT$) | 週期 | 備註 |
|---|---|---|---|
| 房租 | 實際租金 ± 0 | 每月 | |
| 電費（台電） | 500 – 3,000 | 每月，跳過 1 期（＝雙月） | 夏月電價會偏高，範圍抓寬一點 |
| 水費 | 100 – 800 | 每月，跳過 1 期（＝雙月） | |
| 手機月租 | 實際月租 ± 50 | 每月 | |
| 家用網路 | 實際月租 ± 50 | 每月 | |
| Netflix | 依方案 | 每月 | 訂閱費以外幣計價時，信用卡帳單金額會隨匯率浮動，範圍抓 ±10% |
| Spotify | 依方案 | 每月 | |
| YouTube Premium | 依方案 | 每月 | |
| iCloud | 依方案 | 每月 | |
| 年繳保險 | 年繳保費 | 每年 | 與「年度保險費」存錢筒搭配 |

> 每年檢查一次訂閱清單：**三個月沒用過的就退訂**。

## 7. 標籤 Tags（跨分類的橫切面）

分類回答「是什麼」，標籤回答「為了哪件事」。只在需要彙總某個事件時才用：

- `旅行-2026-日本`：一次旅行的機票、住宿、餐飲雖分屬不同分類，用標籤就能算總花費。
- `待報帳`：代墊、公司要還的錢；報完帳移除標籤。
- `import-*`：Data Importer 自動加上，用來追蹤或撤銷某一批匯入。

## 8. 設計取捨紀錄

- **為什麼只有 3 個預算？** 每個分類都設預算，月底會有 13 個紅綠燈，最後全部忽略。三層預算只回答一個問題：本月哪一層超支？
- **為什麼支出帳戶不預建？** 商家名單是無底洞，交給匯入自動長出來，只在重複時合併。
- **為什麼信用卡是資產帳戶？** Firefly III 把信用卡當成餘額為負的資產帳戶，刷卡記支出、繳費記轉帳，帳才不會重複。
