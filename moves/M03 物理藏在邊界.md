# M3 物理藏在邊界

**一句話**：bulk 是課本，邊界、邊角案例、簡併極限才是結構（與誤解）現形處。

## 細枝（具體戰術）
1. **邊界態偵察**：任何有能隙系統先問「切開後邊界有沒有 zero mode」——有 = 拓撲非平庸的第一嫌疑。
2. **邊界當診斷儀**：用邊界測 bulk——Andreev 邊態讀配對對稱性、winding 讀拓撲數；量不到 bulk 時量 edge。
3. **尖銳極限的相位帳**：硬牆/尖銳位勢不是簡化，是每次反射記一筆 Berry phase π 的帳——極限化簡會產生新物理，不只丟物理。
4. **教學用法**：考學生永遠出邊角案例（簡併、非厄米、零溫、半填滿）——bulk 答對不代表懂。

## 觸發訊號
- 「bulk 性質都算完了」→ 問邊界；「模型太理想化」→ 檢查理想化極限是否自帶新相位結構。
