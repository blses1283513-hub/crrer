# M5 二次審問

**一句話**：每個第一遍（mean-field）答案都要過第二遍：哪個被忽略的漲落殺掉它？

## 細枝（具體戰術）
1. **殺手清單**：固定檢查表——Goldstone 模、低維 Mermin-Wagner、相位漲落、無序、有限溫、有限尺寸。每個 mean-field 結果指名一個頭號殺手候選。
2. **問譜不問有無**：「有沒有序」是入場券，「激發譜長什麼樣」才是論文（DMS 三支激發都是 mean-field 看不到的）。
3. **漲落的定量化**：高斯展開＋Ginzburg 判據，把「可能有漲落」變成「漲落修正是 x%」。
4. **答案太漂亮警報**：什麼都能解釋 = 最可疑的時刻；先找它「不能」解釋什麼。

## 觸發訊號
- 學生對第一遍解太滿意；理論與所有數據都吻合卻無獨有預測。
