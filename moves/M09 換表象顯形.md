# M9 換表象顯形

**一句話**：卡住不是更用力算，是換到讓隱藏結構顯然的變數。物理一直都在，座標對了才看得見。

## 細枝（具體戰術）——表象變換清單
1. **基底旋轉**：電子 → Majorana（SO(8) 顯形）；site 基底 → Bloch 向量 d(k)·σ（winding 顯形）。
2. **對偶對調**：θ↔φ 場對調一對，Hamiltonian 塌成對稱形（SO(8) 論文第四對場）。
3. **複變編碼**：兩個實變數 (r, 相位) 合成 z=re^{iφ}，非均勻轉動的幾何顯形（U(1) 神經元瓶頸）。
4. **積掉重寫**：換到有效作用量表象，被積掉部分的印記顯形（連到 [[M10 積掉可解保留印記]]）。
5. **算符 ↔ 路徑積分**：ordering 問題在算符側顯形，幾何相位在路徑積分側顯形——挑讓困難顯形的一側。
6. **換到讓「所需變換變對角」的基底（W02, cond-mat/0306159）**：當你需要一個變換 L 把某個矩陣對稱化/化簡，而在原基底「連 L 存不存在都難證」——換到讓 L **對角**的基底（Majorana 使對稱化矩陣對角，RG 位勢才存在）。判準：變換一對角，原本卡死的存在性問題就消失。這是 [[M11 把動力學變成幾何]] 的關鍵子步驟。

## 觸發訊號（何時該換）
- 對稱「幾乎」成立、就差一點 → 藏著非局域變換。
- 公式又長又醜（[[M04 一行有效理論]] 的醜警報）。
- 耦合比值鎖定但當前變數看不出原因（[[M01 在可控處計算]] 的簽名）。

## 操作口訣
先猜「什麼結構應該存在」（對稱？拓撲數？守恆量），再反推「哪個變換能讓它顯形」——方向是結構→變換，不是亂試變換。
