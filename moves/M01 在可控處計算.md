# M1 在可控處計算

**一句話**：從有具名小參數的角落誠實起算，讓系統性流動（RG）揭露普適結構。

## 細枝（具體戰術）
1. **具名小參數**：說不出小參數（弱耦合、大 N、稀薄、1/半徑），就不是計算，是變分猜測。
2. **角落掃描**：解不動全問題時，列出所有可精確處理的極限角落，挑最接近目標物理的那個進場。
3. **普適性簽名**：追蹤「與初始條件無關的量」——耦合比值、臨界指數、剛度。比值鎖定 = 流向普適結構的訊號（SO(8) 特殊射線）。
   - **細枝（W02, 0911.0166）**：當一堆量在同一尺度看起來**一樣大（都 marginal）**，別比當下量值——比它們**逼近奇異點的冪次**。設 g_i ~ G_i/(l_d−l)^{γ_i}，用**指數 γ_i** 排序：衝向臨界點越陡越關聯（γ=1 主導、3/4 次、1/2 再次、0 無關）。8 個壓成 4 階，最陡那個單獨決定物理。用漸近**速率**排序競爭者，不用當下值。
4. **先流動再猜測**：弱耦合 RG 流的趨勢，比直接猜強耦合答案可靠；順著流外推，標明外推處。

## 觸發訊號
- 學生想「直接解完整問題」而卡死 → 退回可控角落。
- 結果對微觀細節敏感 → 還沒流到普適區，別下結論。
