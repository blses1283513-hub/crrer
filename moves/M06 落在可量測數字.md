# M6 落在可量測數字

**一句話**：以證偽實驗收尾；設計與對手理論「標度不同」的指紋。

## 細枝（具體戰術）
1. **指紋設計**：找一個在你的理論與對手理論中**標度行為不同**的量（DMS：剛度 ∝1/m* 且與 J 無關 — RKKY 做不到）。「都能解釋」不算證據，「只有我能預測」才算。
2. **證偽句式**：每個主張配一句「若量到 X 則本理論死」。寫不出這句 = 還不是科學主張。
3. **探針對表**：理論量 ↔ 實驗探針一一對應（能隙→譜峰、剛度→磁振子色散、相變→比熱跳變）。
4. **數字精度分級**：能給數值給數值（√3m、5% 比熱跳變），不能給數值給冪次，不能給冪次給不等式。

## 觸發訊號
- 論文寫完但沒有「實驗區」；理論優勢只剩「更自然」「更優雅」。
