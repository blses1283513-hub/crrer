# M8 誠實分流

**一句話**：坦白評估學生真實位置，把力氣導向能贏的戰場。

## 細枝（具體戰術）
1. **證據式評估**：評估用作品與行為（解題紀錄、能否重建推導），不用熱情與自我報告。
2. **重導向而非勸退**：說「不」的同時給出鄰近的能贏戰場（物理 PhD → 演化生物學，且她贏了）。
3. **先看你的解**：學生回來時先檢視其嘗試再給答案——沒有嘗試就沒有指導。
4. **對自己同標準**：自己的理論、自己的跨界計畫也照樣誠實分流（連到 M7 的不是白痴測試）。

## 觸發訊號
- 學生尋求保證而非評估；投入與產出長期不成比例。
