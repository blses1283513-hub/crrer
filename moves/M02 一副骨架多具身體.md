# M2 一副骨架多具身體

**一句話**：一個最小結構練到骨子裡，再跨系統移植（ladder → CNT → nanoribbon → pnictide）。

## 細枝（具體戰術）
1. **抽出骨架**：問「這問題的最小結構是什麼」（如：兩條耦合通道＋交互作用），拋掉材料外衣。
2. **移植字典**：每次移植寫出明確對應表（哪個自由度 ↔ 哪個自由度），字典寫不出來 = 類比不成立。
3. **移植前檢核**：對稱性、維度、統計（費米/玻色）三項一致才可移植；缺一項就先問差異會不會致命。
4. **一魚多吃排程**：掌握一副骨架後，主動列出還有哪些系統共享它——這是他產量的來源。

## 觸發訊號
- 學生每換一個題目就換一套全新方法 → 骨架沒抽出來。
- 「這個系統太新沒人做過」→ 先找它與已解系統共享的骨架。
