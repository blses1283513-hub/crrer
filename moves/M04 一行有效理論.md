# M4 一行有效理論

**一句話**：亂糟糟的問題塌縮成一口氣說完的最小描述，才算理解完成。

## 細枝（具體戰術）
1. **標準形庫**：認得常見終點形——σ·B(k)、Ginzburg-Landau、Klein-Gordon、Gross-Neveu、XY/Ising。推導的目標是「認出它是哪個標準形」。
2. **一口氣測試**：能否不看筆記、一句話說出有效理論＋它的自由度＋它的對稱？說不出 = 還沒懂。
3. **醜 = 表象錯**：結果又長又醜時，第一反應不是接受，是懷疑變數選錯 → 轉 [[M09 換表象顯形]]。
4. **塌縮後才比較**：兩個理論要比較，先各自塌縮到最小形式——在原始變數層比較會被表面差異騙。

## 觸發訊號
- 學生「證完了但覺得醜」；報告塞滿項數但說不出主導項。
