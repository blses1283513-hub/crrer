# M10 積掉可解保留印記

**一句話**：可精確處理的部分積掉，保留它留下的推遲、非局域記憶；禁止用靜態平均替代。

## 細枝（具體戰術）
1. **可積判準**：掃描模型中的雙線性部分、快變數、高頻自由度——這些是「可精確積掉」的候選。
2. **產物檢查**：積完的有效作用量**必須**帶推遲/非局域項；若得到瞬時、局域的有效理論，多半是哪一步偷做了靜態平均——回頭查。
3. **平均警報**：聽到「把 X 的效應取平均代入」就攔——先問 X 是否雙線性可精確積掉（DMS：靜態平均=RKKY，丟掉全部三支激發）。
4. **與 M5 分工**：M10 管上游（別做壞近似），[[M05 二次審問]] 管下游（近似做了之後查漲落）。兩招常連發。

## 觸發訊號
- 「浴/環境/快自由度用平均場代」；有效理論瞬時局域得可疑。
