## 0. 安裝

前提：已安裝並啟動 Docker Desktop（之前裝 InvenTree 時已裝）；C 槽至少 15 GB 可用空間。

1. 用瀏覽器下載最新的專案 zip 並解壓縮（同 InvenTree 安裝指南第九章的下載網址）。
2. 開 PowerShell（不需要系統管理員），切到解壓後的 `nila-erpnext` 資料夾：

   ```powershell
   cd "C:\Users\Ande\Downloads\DEMOO\update-日期\crrer-claude-sharp-brahmagupta-tnbukb\nila-erpnext"
   powershell -ExecutionPolicy Bypass -File .\install-erpnext-trial.ps1
   ```

3. 設定管理員密碼（輸入兩次），確認變更後輸入 `Y`。第一次下載約 1.4 GB，整體約 10–30 分鐘。
4. 最後應看到 **「全公司預計庫存 -2；補貨目標 10；建議補貨 12」** 與「完成！」，瀏覽器會自動開啟 <http://localhost:8080>。
5. 中途失敗：直接再執行一次（會沿用密碼，已建立的資料不會重複）。
6. 自動驗證 13 項（只做一次）：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\verify-erpnext-trial.ps1
   ```

   應顯示「結果：13/13 項通過」。

## 7. 手機（門市掃碼的前置評估）

手機要和電腦在同一個 Wi-Fi。先在電腦**以系統管理員身分**開 PowerShell 開放 8080 埠（試用完可刪除此規則）：

```powershell
New-NetFirewallRule -DisplayName "ERPNext 試用 (TCP 8080)" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow -Profile Private,Domain
```

手機瀏覽器開 `http://電腦IP:8080`（電腦 IP 用 `ipconfig` 查）。

## 9. 結束試用

- 暫停：在 `C:\Users\Ande\nila-erpnext-trial` 執行 `docker compose stop`；再開：`docker compose start`。
- 完全移除（**資料全部消失**）：在同一資料夾執行 `docker compose down -v`，再刪除該資料夾。
- 映像約 7 GB 會留在 Docker 中；要釋放空間可執行 `docker image rm frappe/erpnext:v16.50.0 mariadb:11.8 redis:6.2-alpine`。
