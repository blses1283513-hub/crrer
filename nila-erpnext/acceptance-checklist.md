# 妮菈穿戴甲系統 驗收清單（1.0.0）

在**你自己的電腦（階段 A）**用範例資料完整跑一遍；在**客戶的電腦（階段 B）**正式資料匯入後，先備份，再快速跑一遍，最後還原到「驗收前」那份備份，把測試的交易清掉（步驟見 [`windows-verification.md`](windows-verification.md)）。

每一項打勾 ✅ 或寫下看到的問題。有問題的項目請記下：哪個帳號、哪個畫面、做了什麼、看到什麼訊息（可以截圖，**不要截到密碼或 API 金鑰**）。

先在「帳號管理」為每個層級各建一個測試帳號，店長與店員都選「分公司A」。
