# InvenTree 中文操作助手

> **已內建到「庫存管理系統 App」**（見 `../inventree-app/`）。使用 App 的電腦不需要再安裝 Tampermonkey；本頁的安裝方式只在不使用 App 時需要。

一支瀏覽器擴充腳本，替 InvenTree 加上：

| 功能 | 說明 |
|---|---|
| 💡 滑鼠停留說明 | 滑鼠停在選單、按鈕、分頁、欄位上約 0.5 秒，跳出中文操作說明。右下角「💡 操作說明」按鈕可開關。 |
| 📦 調貨提醒 | 打開「轉移庫存」視窗時，右上角跳出提醒小視窗，並**即時**顯示：本次幾筆、來源公司、目的公司。選到別家公司的庫位時會變成橘色警告，提醒改用銷售單＋採購單。可勾選「今天不再提醒」。 |
| ⚠️ 異常數量警告 | 在 InvenTree 的移除／轉移／盤點／新增庫存視窗按「送出」（或按 Enter）時檢查：數量 ≥ 100（`CONFIG.largeQty`）、超過現有庫存、或會讓庫存歸零，就跳出確認視窗，按「確認繼續」才送出。InvenTree 伺服器本身不會擋超量（移除會直接扣到 0、轉移會整批搬走），所以這層檢查很重要。 |
| 🔀 快速調貨 | 右下角「🔀 快速調貨」：輸入料號搜尋 → 依公司分色顯示各庫位庫存 → 點選來源、選目的、填數量與備註 → 送出。即時顯示異常（跨公司、大量、超量、歸零），有異常時送出前要求確認。可跨公司。 |
| 📋 異動紀錄 | 右下角「📋 異動紀錄」按鈕，查詢所有庫存異動的**時間、操作人**、動作、料號、品名、庫位、數量與備註。可依日期、公司、操作人、料號篩選，並匯出 CSV（Excel 可直接開啟）。 |

異動紀錄本身是 InvenTree 自動記錄的（每次入庫、出貨、轉移、盤點都會記下時間與操作人），這支腳本只負責把它們集中查詢與顯示，不會修改任何資料。

## 第一步：介面改成繁體中文（不需腳本）

- 登入頁下方的語言選單選「繁體中文」；或
- 登入後點右上角的使用者選單，進入設定（Settings）的顯示（Display）頁，把語言（Language）改成「繁體中文」，再按 Ctrl+F5。

> InvenTree 的中文由社群翻譯，少數畫面可能仍是英文。

## 第二步：安裝 Tampermonkey

1. 在 Chrome 或 Edge 安裝擴充功能 **Tampermonkey**（從瀏覽器官方擴充商店）。
2. **Chrome／Edge 新版必做**：進入擴充功能管理頁（Chrome 是 `chrome://extensions`，Edge 是 `edge://extensions`）。在 Tampermonkey 的「詳細資料」中開啟「**允許使用者指令碼**（Allow User Scripts）」；若沒有此選項，改為開啟右上角的「開發人員模式」。不開的話腳本不會執行。

## 第三步：安裝腳本

1. 點瀏覽器右上角的 Tampermonkey 圖示，選「建立新腳本」（Create a new script）。
2. 刪掉編輯器裡的預設內容，把 `inventree-ui-helper.user.js` 的**全部內容**貼上。
3. 按 Ctrl+S 儲存。
4. 回到 InvenTree 頁面按 Ctrl+F5。右下角出現「💡 操作說明」與「📋 異動紀錄」兩個按鈕，就代表安裝成功。

每台要使用的電腦都要裝一次。

## 設定

腳本開頭的 `CONFIG` 可以調整：

```js
companies: ['A 公司', 'B 公司', 'C 公司'],  // 要和頂層庫位名稱完全一致
hoverDelayMs: 500,                            // 滑鼠停留多久才顯示說明（毫秒）
largeQty: 100,                                // 單筆數量達到此值視為「大量」，送出前要求確認
auditMaxRows: 2000,                           // 異動紀錄一次最多顯示幾筆
```

如果你在 `inventree-seed/config.json` 改了公司名稱，這裡也要改成一樣，跨公司判斷才會正確。

若 InvenTree 不是用 `http://localhost` 開啟（例如改用電腦 IP），要在腳本開頭的 `@match` 加一行，例如：

```
// @match        http://192.168.1.20/*
```

操作說明的文字在 `HELP` 清單，可自行增修。每一條是「比對文字 → 說明」。

## 限制與已知狀況

- **只在測試頁面驗證過**：我用模擬 InvenTree 畫面與 API 的測試頁，在 Chromium 驗證了三項功能。但還沒在真的 InvenTree 1.5.6 上執行過。如果某些按鈕沒出現說明，或調貨提醒沒跳出來，請把該畫面的截圖（或按鈕上的文字）告訴我，我再補比對規則。
- **說明靠比對按鈕文字**：InvenTree 改版若改了按鈕文字，部分說明可能失效，需要更新 `HELP` 清單。
- **調貨的公司判斷**：腳本從視窗內的文字辨識公司名稱。如果庫位顯示的不是完整路徑（例如只顯示「主倉」），就判斷不出是哪間公司，此時只會顯示一般提醒。
- **異動紀錄的範圍**：只包含**庫存**的異動。修改零件名稱、參數等主資料的紀錄不在其中。
- **查詢速度**：資料量大時，請縮小日期範圍。
