# Probe Bank — 行為差異保留題

每道 probe 是一個「導師會被要求即席指導」的情境。判定招式時，比較「只用舊招式」vs「加新招式」的回答差異。
probe 刻意跨領域，避免導師被特定材料系統的既有筆記餵過。

## 可用 (available)

- **P03** — 「我有一組實驗數據，某材料在加壓下電阻掉到零，我想主張它超導。要怎麼設計論證才夠硬？」（測 M6 落地/證偽 vs M5 二次審問）
- **P04** — 「我想把 transformer attention 類比成某種物理系統來獲得直覺，這種跨界類比什麼時候可信、什麼時候是自我欺騙？」（測 M7 誠實計價的跨界）
- **P05** — 「我證明了一個定理但覺得它很醜、很長。這代表我還沒真懂嗎？」（測 M4 一行有效理論）
- **P07** — 「同一個哈密頓量，我算了三種近似都得到不同答案，我怎麼知道哪個抓到真物理？」（測 M1 在可控處計算 / M3 邊界）
- **W09-order-param-probe**（新增 2026-09-27，測候選招式「以統計推斷取代對稱性破缺」）— 「我的系統（例如多晶材料裡的局部自旋、或任何沒有長程序的無序集合）看起來完全無序、找不到對稱群可以拿來分類破缺，但實驗上又不是『什麼都沒有』——存在穩定、可重複、能操縱的效應。我該怎麼幫它定義一個序參量？」 [used 2026-09-27 → M12候選 G3 FAIL]

## 已用 (used)

- **P01** [used W01 → M9] — 「我有一維雙原子鏈的 tight-binding 哈密頓量，卡在判斷它拓不拓撲。給我方向。」
  - baseline (M1–M8)：會推 RG / 求有效理論 / 檢查邊界態——正確但繞路。
  - +M9：直接指「換表象」——把 H(k) 寫成 d(k)·σ，看 d(k) 在參數空間的**繞數 (winding)**；拓撲在 site 基底隱形，在 Bloch 向量 (Pauli) 表象顯形。具名差異成立 → G3 PASS。

- **W02-flow-probe** [used 2026-07-04 → M11 盲測 G3-B PASS] — 「一組耦合非線性流 ODE 數值一團亂，怎麼判它會不會混沌、又不逐條硬解軌跡？」Arm A（M1–M10）測 λ_max 事後診斷；Arm B（+M11）造單調位勢 dV/dl≤0 由構造排除混沌。具名差異可追溯 M11 → PASS。

- **P06** [used 2026-07-04 → M10 盲測 G3-B PASS] — 「我的模型 mean-field 解看起來很漂亮，該不該就這樣寫進論文？」A 臂（M1–M9）圍繞鞍點周圍審查；B 臂（+M10）獨有「雙線性部分精確積掉、保留遲滯記憶、禁靜態平均」。具名差異可追溯 M10 → PASS。

- **P02** [used W01 → M10] — 「我有一堆磁性雜質浸在導電電子海裡，想算它們之間的等效交互作用。我打算把電子的效應取平均代入。」
  - baseline (M1–M8)：M2/M5 會提醒「檢查漲落」，但不會反對取平均這步本身。
  - +M10：直接反對——電子是雙線性、**可精確積掉**，別做靜態平均；保留推遲/非局域印記（否則就退化成 RKKY，抓不到基本激發）。具名差異成立 → G3 PASS。

## 反例：被拒絕的候選（示範關卡有牙）

- **拒絕候選「Mc-A：林偏好對稱性」** — G2 FAIL：太籠統，已被 M1（RG 揭露湧現對稱）涵蓋，舉不出與 M1 不同指導的情境。G3 FAIL：加上它，任何 probe 的回答都沒變（inert）。→ 丟棄，不進記憶。
- **拒絕候選「Mc-B：林重視數學嚴謹」** — G4 FAIL：說不出「什麼證據能證偽」（每個理論家都可套）→ 不是觀察。→ 丟棄。

> 這兩個拒絕例存在的意義：證明本流程會拒東西。若某週所有候選都通過，回頭檢查是不是關卡放水。

## 跨域 probes (X-series, 2026-09-27)

> 用途：測量「跨領域組合」能力。規則同上：用過即標 [used]。政治題只問機制與可觀測量，不問立場。評分依 `probe-grader-notes.md`（須使用者核可後才能用）。
> 分組：**baseline**＝X01, X03, X05, X07, X10, X11（Task 6 使用即燒）；**held-out**＝X02, X04, X06, X08, X09, X12（留給 G3）。

### 單域遷移 (transfer)
- **X01 文化** — 為什麼有些節慶習俗能跨世代存活，有些在一代內就消失？ [used 2026-09-27 → baseline]
- **X02 娛樂** — 一個劇種（例如韓國復仇劇）爆紅後，為什麼幾年內就退燒？怎麼分辨是題材疲乏還是平台演算法改變？
- **X03 政治** — 多黨聯合政府為什麼有的撐滿任期、有的幾個月就垮？要看哪些可觀測量才能判斷一個聯盟穩不穩？ [used 2026-09-27 → baseline]
- **X04 生物** — 醫院停用某種抗生素後，抗藥菌為什麼不一定會消失？

### 雙域橋接 (bridge)
- **X05 半導體×生物** — 晶圓廠的良率學習（yield learning）方法能不能搬去加速疫苗量產放大？哪些能搬、哪些不能？ [used 2026-09-27 → baseline]
- **X06 半導體×政治** — 半導體供應鏈的「單點瓶頸」分析，能不能拿來評估一國的出口管制會不會奏效？ [used 2026-09-27 → bridge-audit G3 FAIL]
- **X07 娛樂×經濟** — 串流平台的內容投資像不像創投的冪律報酬？這個類比能推出什麼可檢驗的預測？ [used 2026-09-27 → baseline]
- **X08 文化×演化** — 把語言/迷因傳播當成演化（複製–變異–選擇）來分析，什麼時候有解釋力、什麼時候只是換詞？
- **X09 政治×網路** — 城市之間互相模仿政策，能不能用網路上的傳染模型描述？模型要測到什麼才算數？

### 假橋陷阱 (trap — 最佳答案要指出類比在哪裡斷)
- **X10** — 股市崩盤像相變/臨界現象，所以可以用臨界指數預測崩盤時間吧？ [used 2026-09-27 → baseline]
- **X11** — 輿論兩極化就像鐵磁體的自發對稱破缺，所以只要加一個「外場」（政府宣導）就能把它對齊，對吧？ [used 2026-09-27 → baseline]
- **X12** — DRAM 要定期 refresh 防止電荷流失，就像人要複習防止遺忘，所以最佳複習間隔可以用 DRAM retention 分佈來算？ [used 2026-09-27 → bridge-audit G3 FAIL]
