**Title:**

Add a LICENSE file?

**Body:**

Hi Narain, thanks for sharing sem-toolkit. The thin-film metrology and PECVD DOE modules are a nice
way to learn how these analyses connect.

The repository currently has no LICENSE file. Under GitHub's terms that means people can view and fork the
code, but they have no permission to reuse, modify, or redistribute it, even when the project is public and
meant for learning.

Would you consider adding an open-source license? If you're unsure which one:

- **MIT** or **Apache-2.0** (permissive: others can reuse the code with attribution)
- **GPL-3.0** (copyleft: derivative work must stay open source)

https://choosealicense.com/ has a short chooser, and GitHub can add one via
"Add file > Create new file > name it LICENSE" (it offers license templates).

If you'd rather keep all rights reserved, that's completely your call; a short note in the README saying so
would help readers know where they stand.

Thanks again!
