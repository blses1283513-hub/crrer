# 開場：先把兩個黑盒都定義出來

在猜「能不能搬」之前，先誠實寫下兩邊的黑盒——輸入是什麼、輸出是什麼、回饋迴路長怎樣。類比講得漂亮但寫不出這張表，就只是修辭，不是科學（M7 的第一條戒律）。

**晶圓廠良率學習的黑盒**
- 輸入：曝光/蝕刻/沉積等製程參數、光罩設計、原物料批次
- 輸出：die-level pass/fail（電性測試 e-test，每片晶圓上千個測試點，**秒級**出結果）
- 回饋迴路：量測 → 缺陷圖（defect map）→ 製程調整 → 下一批晶圓 → 再量測。一天可以跑完好幾輪。
- 數學骨架：Poisson / Murphy / negative-binomial 良率模型，核心是
$$Y = \exp(-D_0 A_{\text{crit}})$$
（$D_0$=缺陷密度，$A_{\text{crit}}$=關鍵面積），假設缺陷是**外生、獨立同分布、空間隨機**的顆粒污染。

**疫苗量產放大的黑盒**
- 輸入：細胞株/病毒種子、培養基、生物反應器條件（溫度、pH、溶氧、攪拌剪切力）、純化層析條件
- 輸出：批次是否放行——titer（產量濃度）、purity、potency/免疫原性、無菌性。**關鍵 assay 是週級**（potency/immunogenicity 常要數天到數週，且是每批一組數據，不是每片千點）。
- 回饋迴路：一批發酵/純化 → 送檢 → 數週後才知道這批"好不好" → 才能調下一批的製程參數。一個製程開發週期可能一年只跑幾十批。
- 數學骨架：目前主要是機制模型（代謝動力學、傳質方程）+ 統計製程管制，還沒有像 Murphy 模型那樣被普遍接受的"生物良率通用公式"——因為失敗機制本質上更異質。

這兩個黑盒的差異，才是回答"能不能搬"的真正依據，不是"兩者都叫 yield"這個表面巧合。

# 對「能不能搬」先做關聯度分流（relevance filter）

在鑽進任何一個因子之前，先分類——這是深度優先的節育條款：只對會改變結論的因子深挖。

**relevant（會改變結論或行動）**
1. 回饋迴路頻率差距：秒級 vs 週級，相差 $10^4$–$10^5$ 倍
2. 法規鎖定：半導體製程可持續微調；生物藥是「process = product」，上市後製程變更要重新驗證/re-filing
3. 變異源本質：外生顆粒缺陷（決定論物理 + 隨機顆粒）vs 內生生物噪聲（細胞株漂移、代謝異質性、宿主基因體不穩定）
4. 歷史數據量級：一天上萬片晶圓 vs 一年幾十批，統計檢定力（power）差幾個數量級

**marginal（只改變信心，不改變結論）**
- 產品幾何複雜度（2D 光罩佈局 vs 3D 反應器流場）
- 兩個產業的資本規模數字

**irrelevant（點名一次即丟）**
- 「兩者都叫 yield」——名字相同不代表機制相同，這是最容易誤導人的假朋友（false friend）
- 「兩者都是高科技製造業」——泛泛分類，不提供任何可操作訊息

# 直接回答：哪些能搬、哪些不能（M7 誠實計價）

## 能搬的（工具骨架，M2：一副骨架多具身體）
- **SPC 控制圖**（Xbar-R、CUSUM、EWMA）：只要有連續量測訊號，骨架直接適用於監控 CQA（Critical Quality Attribute）。
- **DOE（實驗設計）尋找製程窗口**：這條其實**已經搬過去了**——ICH Q8/Q9/Q10 的 QbD（Quality by Design）框架，design space 概念，本質上就是從六標準差/DOE 借來的方法論。不是新鮮事，是已經發生的移植。
- **多變量分析（PCA/PLS）做 soft sensor / 製程監控**：概念可搬——用可測的（拉曼光譜、離線代謝物）推不可測的（即時 titer），但模型本身要在生物數據上重新掙得，不能把半導體的模型參數帶過去。
- **良率-爬升曲線的溝通框架**：跟管理層/投資人溝通"這是正常的學習曲線，不是失敗"這件事，形式上可以借用，但底層擬合函數要重新推。

## 不能直接搬的（斷點，需要重新推導）
- **Poisson/Murphy 缺陷密度模型本身**：假設空間隨機、獨立同分布的外生顆粒缺陷。生物系統的失敗更常是重尾、批次相關（同一批細胞株漂移會系統性拖垮整批，不是隨機顆粒式的）。把 $Y=\exp(-D_0A)$ 套到生物良率上是**形式借用，物理錯誤**。
- **秒級線上學習這件事本身**：晶圓良率學習之所以有效，是因為回饋迴路快到一天能跑好幾輪 RG-like 迭代。疫苗的關鍵 assay 是週級，這代表"線上學習"在生物端**物理上不成立**，只能做慢速的 batch-to-batch 學習，速度差 $10^4$–$10^5$ 倍。這不是工程能力問題，是回饋迴路頻率的硬限制。
- **製程持續微調的自由度**：半導體良率上市後還能天天優化；生物藥製程一旦鎖定，法規把它焊死了，"持續優化"這件事的空間被大幅壓縮。
- **數據驅動方法的統計功效**：半導體良率學習底層假設有海量數據支撐 ML/統計模型；生物製程一年幾十批的樣本量下，很多"資料驅動"手法根本沒有統計功效，會過擬合出假訊號。

# 跨域物理橋接（把類比寫成雙語字典，不是修辭）

## 橋接一：良率缺陷模型 ↔ 髒超導體的 pair-breaking

| 半導體良率 | 髒超導體（Abrikosov-Gorkov） |
|---|---|
| 缺陷密度 $D_0$ | 雜質濃度 $n_{\text{imp}}$ |
| 關鍵面積 $A_{\text{crit}}$ | pair-breaking 截面 |
| 良率 $Y=\exp(-D_0A)$ | $T_c$/能隙 $\Delta$ 隨雜質濃度指數壓低 |

> **深談（Deep remark）**：兩邊的共同結構是「淬火無序（quenched disorder）壓低一個宏觀輸出」。但斷點在這裡——超導序參量是有相位相干性、有恢復長度的連續場，缺陷壓低的是一個**連續**的宏觀波函數；晶片良率是二元 pass/fail 的計數統計，沒有相位、沒有"恢復長度"這種東西。**這個類比在"隨機點過程壓低巨觀量"這層是對的，一旦你想往動力學（相干長度、臨界指數）推,就斷了。**

## 橋接二：良率學習曲線 ↔ RG 流向固定點

| 半導體良率學習 | RG 流 |
|---|---|
| 每一輪「量測缺陷圖→調製程→再量測」 | 一步 RG 迭代 |
| 良率爬升曲線（65%→95%） | 流向一個穩定固定點的單調位勢下降（M11 的精神） |
| 一天能跑好幾輪 | 每天好幾個 RG 步 |
| 生物製程一年幾十批 | 整個計畫生涯只有 10–20 個 RG 步 |

> **深談**：「存在一個可以收斂到的固定點」這個**幾何**事實，可能兩邊都成立——這是 protected 的部分。但斷的是**你負擔得起幾步迭代**。半導體是幾千步迭代裡找固定點，生物製程整個開發計畫可能只夠跑 10~20 步。同一個幾何圖像,兩邊迭代預算差了兩三個數量級,這就是為什麼「這方法能收斂」不等於「這方法划算」。

# 保護 vs 脆弱

**Protected（跨域不變的原則）**
- 「回饋迴路收斂速度被量測頻率上限鎖死」——這是控制論/資訊論層次的事實，兩邊都適用，不依賴任何產業細節。
- 「品質內建進設計（QbD）優於事後補救」——這條原則本身就是半導體/六標準差傳統早就驗證過、後來被生物製藥業正式吸收的（ICH Q8）。

**Fragile（模型相依，不能帶著走）**
- Poisson/Murphy 的具體函數形式——沒有生物失效數據支撐前,不准直接套用。
- 「歷史數據量體足夠支撐 ML 方法」這個假設——在生物製程的小樣本下站不住。

# 可證偽收尾（M6）

一個能檢驗這整套判斷的前導實驗：在一個生物反應器製程單元上，加裝 PAT（Process Analytical Technology，如即時拉曼光譜、off-gas 分析）做成"準連續"的替代量測訊號，逼近半導體 in-line metrology 的密度，再套用 SPC 控制圖做 batch-to-batch 回饋。

**指紋**：如果 $n=10\text{–}20$ 批的前導測試中，批次失敗變異度相對歷史基線沒有統計顯著下降，這就證偽了「晶圓良率工具骨架可以直接搬」這個假設——代表瓶頸不在"有沒有上 SPC"，而在更深的東西（很可能是變異源本質或法規鎖定,而非工具）。

## ☆ 課後題

半導體良率學習裡，Murphy 模型比純 Poisson 模型多考慮了「良率的良率」（yield of yields，把 $D_0$ 本身當隨機變數積分掉）。試著自己想一次：如果疫苗製程也想寫一個類比的"二階"模型——把批次失敗率本身的**批次間變異**（而不是批次內變異）當隨機變數積分掉——這個二階模型會長什麼樣子？它能不能救回橋接一裡斷掉的「連續 vs 二元」問題？下次見面前先寫下你的猜測，不要先查文獻。

## 結論草稿
- 主張: 晶圓廠良率學習的「統計工具骨架」（SPC、DOE/QbD、多變量監控）可以搬到疫苗量產放大，但其「物理/生物假設」（決定論式外生顆粒缺陷模型、秒級回饋迴路、製程可持續微調的自由度）不能直接搬，因為兩邊在回饋迴路頻率、變異源本質、法規鎖定三個 relevant 因子上結構性不同。
- 推理步驟: (1) 先定義兩邊黑盒的輸入輸出與回饋迴路 (2) 對「能不能搬」做關聯度分流，鎖定四個 relevant 因子 (3) 依 M2 骨架標準逐項檢驗哪些統計工具可以原封不動移植 (4) 依 M7 誠實計價逐項檢驗哪些物理/生物假設會斷裂,並算出量級差距(回饋迴路 10^4–10^5 倍、迭代預算 10^2–10^3 倍) (5) 用兩個雙語字典橋接(缺陷模型↔pair-breaking, 學習曲線↔RG流)驗證類比在哪一層斷裂 (6) 設計可證偽的前導實驗收尾
- 因子分類: relevant: 回饋迴路頻率差距、法規鎖定(process=product)、變異源本質(外生顆粒 vs 內生生物噪聲)、歷史數據量級 / marginal: 產品幾何複雜度、資本規模數字 / irrelevant: 「兩者都叫 yield」的表面巧合、「都是高科技製造業」的泛泛分類
- 使用招式: M7(主框架,誠實計價跨界), M2(骨架移植檢驗), M6(可證偽收尾), M9/M11(跨域表象橋接,RG流幾何類比)
- 跨域橋接: (1) 缺陷密度模型 Y=exp(-D0·A) ↔ Abrikosov-Gorkov pair-breaking，映射：缺陷密度↔雜質濃度、關鍵面積↔pair-breaking截面；未映射項：良率是二元計數統計而超導序參量是連續相干場；斷點：一旦涉及相位相干性/恢復長度就不成立。(2) 良率學習曲線 ↔ RG流向固定點，映射：每輪量測-調整-再量測↔一步RG迭代；未映射項：兩邊可負擔的迭代步數差兩三個數量級；斷點：「存在收斂固定點」的幾何事實可能兩邊都成立，但「划算與否」在迭代預算差距下不成立。
- 自評信心: medium（跨半導體/生物製程兩個產業的具體工程細節，本人非該領域一線工程師，框架與量級判斷有把握，但生物製程的量化細節需要業界資料驗證）
